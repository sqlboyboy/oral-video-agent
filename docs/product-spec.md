# 产品说明：智能口播智能体

## 目标用户

- 短视频创作者
- 带货主播/商家
- 本地生活运营
- 知识口播账号运营者

## 核心流程

1. 用户粘贴抖音链接或上传本地视频。
2. 系统导入视频并识别原口播文本。
3. 用户选择仿写风格，填写产品/服务和目标人群。
4. 系统一键生成新口播文案。
5. 用户选择内置声音或上传授权声音参考。
6. 用户选择内置 BGM 或上传自定义 BGM。
7. 用户调整字幕样式。
8. 系统合成视频并导出 MP4。

## 开发约定

- Python 后端使用 `uv` 管理依赖、虚拟环境和锁文件。
- 后端入口位于 `services/api`，常用命令是 `uv sync` 和 `uv run uvicorn app.main:app --reload`。

## MVP 验收标准

- Windows 和 Android 客户端能连接同一个后端 API。
- 用本地测试视频或链接能创建任务。
- 能展示识别文本和仿写文本。
- 能编辑文案、选择声音、选择 BGM、调整字幕大小。
- 能生成一个成品文件并提供下载路径。

## 后续真实能力接入顺序

1. FFmpeg 真合成：视频 + TTS 音频 + BGM + SRT/ASS 字幕。
2. faster-whisper 本地 ASR。
3. Claude/OpenAI/国产大模型文案仿写。
4. TTS/声音克隆 provider。
5. 抖音链接导入 provider。
6. 用户账号、素材库、历史作品、支付。
